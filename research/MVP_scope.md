# MVP Scope

## Goal

Build a prototype that can detect nighttime scratching events from wearable sensor data.

## Input

Potential sensor data:

- Accelerometer
- Gyroscope
- Sleep/activity data

## Output

The MVP should identify:

- Whether a scratching event occurred
- Event start time
- Event duration
- Number of scratching events

## Out of Scope

The MVP will NOT:

- Diagnose eczema
- Measure eczema severity
- Recommend medical treatment
- Automatically determine the cause of itching
- Replace clinical assessment

## Success Criteria

The first prototype should demonstrate that:

1. Sensor data can be collected during sleep.
2. Scratching events can be manually labeled.
3. Scratching and non-scratching movements can be compared.
4. A basic model can be trained to distinguish the two behaviors.

## Target Users

People with eczema who experience nighttime itching.
